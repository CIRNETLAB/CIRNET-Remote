# Lab-First digital event simulator

Supported CircuitGraph 1.0/1.1/1.2 → offline schema/authoring validation and explicit domain dispatch → VirtualExecutionPlan → deterministic EventQueue / DigitalNet / DigitalDevice / DeviceRegistry / ClockSource → observed event capture. Models include switch/input, AND/74HC08 quad gates, NOT, OR/XOR, LED/probe, clock and the bounded powered-HC08/source/resistor/LED DC subset. Known editor board/instrument visuals create no electrical nets. Other models report UNEXECUTABLE, not a fake result. See [signal domains and simulation](../../docs/architecture/signal-domains-and-simulation.md) and [versioned placement](../../contracts/design-models/flexible-placement.md); supporting a stored graph never grants an execution model to every component.

Nanosecond integer simulation time and configurable digital transport delay (default model 8 ns) are software models, not measured component timing or electrical limits. Floating inputs remain X. Changes at one timestamp settle before capture/evaluation, with stable ordering. Captures contain actual event transitions 0/1/X and a bounded duration; four requested probe channels max, default first four probes/sources. Defaults/budgets: 1 ms capture window, 100,000 queued events, 100,000 capture events; configured limits are software resource bounds. There is no fixed-timestep whole-circuit loop.

VirtualHardwareStation dispatches bounded simulations outside FastAPI's event loop. `NETCIRCUIT_SIMULATION_WORKERS` selects the positive pool size (default 4) in API and Hardware Service. RPC sessions isolate experiments; stop/reset invalidates generations so late results cannot overwrite newer state. AnalogSimulationEngine / SPICEAdapter / MixedSignalCoordinator are explicit UNAVAILABLE boundaries; no SPICE dependency or fake analog capture.

From Remote root, select the reviewed Contracts artifact with `python scripts/install_contracts.py --with-dev --manifest ABSOLUTE_MANIFEST`, then `pip install -e './simulator/circuit-simulator[test]'`. The simulator pins `netcircuit-contracts==1.0.1`; it does not import sibling source Contracts. Tests: pytest -q simulator/circuit-simulator/tests. Real REST→RPC→worker AND integration is in tests/integration/test_virtual_lab_execution.py. Initial grading supports expected signal values held between event timestamps and explicit exercised truth-table vectors.
