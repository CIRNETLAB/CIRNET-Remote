# Lab-First Hardware Service

Local-only process on the Mini PC, behind FastAPI. Authority: ../../docs/ARCHITECTURE.md. HardwareStation abstracts Virtual/Physical; physical start requires scan/safety, typed plan, routing and guarded power-up. Unavailable hardware never returns a physical success.

RPC 2.0 is packaged from net-Circuit-Contracts (`hardware/v2/rpc_v2.proto`); parent v1 protos are deprecated. From Remote root, install the reviewed wheel and DEV tools with `python scripts/install_contracts.py --with-dev --manifest ABSOLUTE_MANIFEST`, then `pip install -e './services/hardware-service[dev]'`. `python scripts/generate_hardware_rpc.py --check` checks installed bindings; both processes use the versioned wheel rather than generating retained source. R3 registers lifecycle handlers. Bind only loopback/Unix.

Physical operations validate current driver/profile capabilities, scan freshness (configurable software TTL, default 30 seconds), runtime safety, endpoint/resource coverage, guarded power/watchdog policy and acknowledged driver actions. Faults attempt safe fallback and invalidate plans; missing driver reports OFFLINE/hardware_applied=false. Runtime interlock/watchdog must protect independently of software polling. Two virtual breadboards are editor fixtures, not physical capacity. Install simulator package too: `pip install -e './simulator/circuit-simulator[test]' -e './services/hardware-service[dev]'` after selecting Contracts. Virtual digital execution/capture uses a bounded process pool, with independent per-experiment sessions; analog/Scope/Generator stay unavailable.

Tests: pytest -q services/hardware-service/tests tests/contracts. Codegen tests compile/inspect v2 in temporary directories and verify deterministic output. Stable domain errors: HARDWARE_UNAVAILABLE, INVALID_STATE, UNSAFE, SAFETY_INDETERMINATE, UNEXECUTABLE, RESOURCE_CONFLICT, PROTOCOL_MISMATCH, TIMEOUT, DRIVER_ERROR. The browser never talks directly to this service.

Set `NETCIRCUIT_SIMULATION_WORKERS` to the same positive integer in API and Hardware Service (default 4). Both systemd units read `/etc/netcircuit/netcircuit.env`. The pool explicitly uses `spawn`; shutdown waits for owned workers before replacement. RPC reserves four additional control threads beyond configured simulation concurrency so Stop remains available during admitted simulations. Physical admission uses current `physical_execution_slots`; actual V1 has one shared fabric, and any quarantined lease blocks that station. Profiles advertising multiple slots require real independent hardware partitions; scheduler tests do not establish such electrical support.

Post-R7 Lab schema 1.0/RPC v2 now carries observed per-pin node bindings and rich diagnostics. Malformed scan evidence (missing nodes, duplicate pins/connections, opaque identity other than UNKNOWN) becomes DRIVER_ERROR with safe fallback. API TopologyResolver computes actual student endpoint bindings before compilation; HardwareStation validates the resulting infrastructure plan without rebuilding internal student wiring. Reference physical node != student physical node.

`instrument_capabilities` is the sole channel/runtime authority; deprecated duplicate counts/availability were removed and protobuf tags reserved. Channels=0 means unavailable. Current virtual Logic Analyzer has four channels, Scope/Generator zero; default physical capabilities all zero. User channels are 1-based. Generator optional waveform/frequency/amplitude/offset limits come only from real profiles and are checked at compiler/native/RPC boundaries. Baseline configuration belongs in the plan before guarded power-up; live changes require RUNNING, runtime_reconfiguration_supported=true, allocated channel and fresh safety. Current runtime flag=false; clock/trigger live control remains NOT_IMPLEMENTED.

Hardware Service produces genuine digital capture evidence; API CaptureService persists it in CaptureStore and publishes metadata separately. Analog capture envelopes do not implement ADC/AFE, DAC/output stage, SDRAM, topology scanning electronics, switching fabric or transport hardware. FPGA tests cover abstract fail-closed contracts/compiler behavior; absent Icarus/vvp is an explicit local skip, and no test here proves electrical safety or target timing closure.

ReadCapture RPC sends bounded NCAP digital data in OperationReply.capture_payload, with metadata-only result_json. Names occur once in the header; 100k events remain below default gRPC receive limits. The API verifies binary/descriptor consistency before storage. Install matching versioned Contracts bindings and restart both services from the same reviewed v2 contract; malformed driver sample evidence fails explicitly.
