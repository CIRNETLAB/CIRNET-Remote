## Implementation

`apps/web/src/App.vue` renders one workbench; compatibility routing redirects to `/`. New workbench/window/scene/files modules replace the seven old pages and five old permanent-panel/dock components. The six stores and existing transport boundary remain.

Twenty supplied SVG icons are consumed through committed derivatives generated by `scripts/prepare_workbench_icons.py`; provenance verifies original artwork. Phase 2 now adds interactive scene/graph editing and a local memory image contract. Execution remains Phase 3+.
