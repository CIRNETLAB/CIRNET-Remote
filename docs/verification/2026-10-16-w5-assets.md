# W5 instrument asset ownership and editor boundaries

The two existing preview entries now consume the delivered self-contained GLBs
through the shared asset provider. Vite builds both preview HTML files alongside
the workspace entry. `apps/web/src/data/instrumentAssets.ts` declares each URL,
SHA-256 revision and 2 MB byte limit. The original model READMEs document the
procedural factories, exporter, named objects, coordinate conventions and artwork
provenance. No model or artwork bytes were regenerated in this phase.

The delivered exports retain older metallic housing materials; the current
workspace factories use the newer coating materials. The main workspace therefore
keeps those procedural factories. The previews exercise the actual imported models
without changing the workspace's appearance or controls. Imported model failure
shows an explicit procedural fallback; it does not imply physical instrument
availability, acquisition or hardware control.

`AssetProvider` owns bounded shared templates and gives each lease an independent
object tree, geometry, material and texture instance. Concurrent references to an
identical URL, revision and byte limit share fetch and decoding. A stricter byte
limit has a separate admission. Last release aborts pending work, disposes the
template and decoded image bitmaps, and removes the cache entry. Failure releases
reference budgets and abort listeners automatically. Fetch bytes, media type,
SHA-256 and fetch/decode time limits are checked before admission. Late decoding
after cancellation is disposed. Preview teardown releases its lease, fallback,
grid, controls, listeners and renderer. CanvasTexture replacement keeps the same
screen mesh and disposes its replaced texture once.

`ScenePicking` now owns geometric ray/segment/plane picking behind the existing
SceneManager facade. `PointerGestureSession` owns exclusive pointer and draft
admission, cancellation and one-shot completion; `useCircuitEditor` retains the
existing preview calculations and graph commands. The editor graph remains owned
by the circuit document store.

Verification includes provider lifecycle and bounds tests, actual GLB SHA checks
and real GLTFLoader decoding, existing scene/gesture/resource regressions, and
real browser cases for both imported previews and the unavailable-model fallback.
The browser cases keep the same canvas during view changes and CanvasTexture
replacement. These checks establish software resource behavior, not physical
hardware behavior.
