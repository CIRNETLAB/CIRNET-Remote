# W6 — Remote lifecycle and assignment authoring

Status: PASS. Software phase gates are verified; Git checkpoint remains blocked by read-only worktree metadata.

Remote request intent now belongs to a pure application controller. Create, Run and Stop have separate durable operation identities. An unreadable or lost response is recovered through the original operation key; Start is never replayed. Stop during pending Create waits for the learned experiment ID and issues one keyed Stop without dispatching Run. Unknown outcomes remain visible and disable Run while bounded read-only reconciliation continues. A newer terminal event wins over an older Run acknowledgement.

One application-lifetime connection scope owns the socket and completion-based, single-flight polling. Refresh/resync triggers coalesce; failures back off and teardown cancels requests/timers. Reload gets authorized recent history, active records and queue positions. Snapshot recovery does not grant this tab live instrument control. The selected historical record, owned active execution and ephemeral control acknowledgement are separate state. Viewing history cannot redirect Stop. Admission remains disabled until an authorized active snapshot succeeds; the four-page recovery budget is explicit and an incomplete snapshot cannot enable Run.

Independent review reproduced six old-principal response races after reset and a new request reused the same numeric request version. A per-store scope identity and AbortController now survive reactive state resets and guard every read publication. History refresh, active pages, queue, assignment lists, selected evidence and active Get cannot repopulate a replacement principal's state. Deep-link history reads also remain read-only. Instructor form scratch fields clear on principal/role/draft changes. Unapplied advanced JSON asks before switching assignments; Keep preserves its exact text and explicit Replace reloads it.

Advanced JSON text is an explicit unapplied UI buffer in the authoring store, with the parsed assignment remaining canonical. All entrypoints, including deep-link navigation, honor its dirty state; closing/reopening the window preserves it, while principal changes clear it. A delayed physical-preview preflight captures the original principal, document, configuration and target. Replacing any of those cancels that Run intent. Stop during preflight prevents all mutation requests; Stop during actual Create retains the original keyed recovery path. Unmount and stale errors cannot submit or update a replacement workspace.

History uses owner-filtered SQL keyset queries and an owner/sequence index. Each page is bounded to100 records; the browser keeps a bounded200-row history window. Active snapshots include unstarted CREATED records for lost-Create recovery but prioritize admitted work and quarantined reservations. Queue ownership checks select only experiment IDs in the existing server queue, without loading historical JSON payloads. The new versioned history DTOs recurse through shared record semantics in Python and TypeScript, including structured nested issue paths. The existing list endpoint remains compatible. All HTTP/operation/event/history views use the same assignment-feedback projection.

Assignment authoring has immutable revisions and a separate stable published pointer. Instructor/Admin routes create, load, save with CAS, list bounded author pages and publish/unpublish. Draft edits preserve the published definition until explicit publication. Student views whitelist disclosed fields and omit private reference designs, expected answers and profiles. Authoring windows support validated reference snapshots, concurrent-edit conflicts and explicit reload/fork without discarding pending edits. Privileged Admin access and publication are audited.

Create resolves the permitted assignment revision before compilation and rechecks that exact revision, visibility and current session in its actual experiment/operation write transaction. Concurrent privatization, publication or revocation rejects stale admission atomically; unpublished draft edits preserve the original published snapshot. The pinned definition remains immutable for later verification. Current feedback policy applies to historical disclosure, without changing stored evidence or grading context. Migration0004 retains existing definitions and validates/adopts a compatible pre-existing history index; incompatible index definitions fail clearly.
