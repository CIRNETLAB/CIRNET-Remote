- Migration `0003_projects`, private relational ownership, immutable graph revisions, database compare-and-swap saves, scoped keyset pagination, soft deletion, audit and explicit guest transfer. Graph identity is independent of server document identity; Save As preserves the embedded graph.
- Create pins graph, configuration and assignment context. Later saves or assignment edits cannot change the admitted experiment. Legacy records have an explicit first-admission/recovery policy. A missing legacy assignment blocks execution without Start.

- The production API rechecks session authority in the actual write transaction.
