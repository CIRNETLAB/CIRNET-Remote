### Final review regressions

Independent source review found three additional edge cases after the initial integrated runs. All were reproduced before correction: JSON autodetection could accept UTF-16/32 while the byte-level depth scanner assumed UTF-8; two tabs could overwrite a shared localStorage ledger before acquiring a common transaction lock; and an expired/revoked deterministic legacy read context could be inserted again under its existing primary key. The corrected request boundary permits valid UTF-8 (including UTF-8 BOM), rejects invalid encoding/raw NUL before depth scanning, and preserves the documented 400 response. Every browser ledger mutation acquires the same Web Lock before reading. Legacy reads return 401 for a dead internal context and bounded maintenance retains its tombstone while the original proof is live; explicit bootstrap can still consume the valid ownership proof. The final review additionally requires Stop tracking to use immediate try-acquire semantics so a held browser storage lock cannot block the explicit Stop request.

The intermediate full Contracts/Python rerun passed Contracts and 1,255 Python tests with one optional skip, but one actual browser-harness startup exceeded its 30 s readiness bound with an empty log during concurrent gates. It is retained as a failed run, not reported as a complete Python PASS. A fresh complete run follows the final encoding/legacy fixes and uses the stable external allocator parent for child processes.

The new asynchronous ledger boundary also reproduced a delayed-intent race: after a user Stop failed while Run waited for the storage lock, releasing that lock dispatched Run and then another Stop. The pre-dispatch fence now checks both cancellation and `stopRequested`; an identity whose command was never sent is removed through best-effort nonwaiting tracking cleanup. The focused six-suite final run passes 46 tests, including this exact race and held-lock Stop availability. Generator commands independently recheck live control after storage commit.

The independent reviewer reran the same controlled-port probe after the fix: Run remains 0 and Stop remains 1 both before and after releasing the storage lock. All findings from that focused source review are closed.
